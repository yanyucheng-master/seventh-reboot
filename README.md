# 第七次重启

《第七次重启》V1.0 是一款以异常通讯界面推进的科幻互动叙事游戏。中文剧情语义真源位于 `story-source/main.zh-CN.txt`，`第七次重启-剧情文本.txt` 是由运行时剧情导出的阅读与审计文件，不作为反向生成源。

## 世界观契约

- Aurora 在前六次任务中发出的外部呼叫 `CALL-01` 至 `CALL-06` 均未获得真实回应。
- 当前玩家是第七次任务中第一个成功回应的外部意识。第一条玩家消息真正送达后，系统才建立唯一身份 `Observer-01`。
- Nova 没有在前六次认识并反复忘记当前玩家；玩家也没有前六轮与 Nova 相处的隐藏经历。
- 第七协议回滚的是 Aurora 与 Nova 的舰内任务状态，当前玩家处于回滚范围之外。
- 第七协议只能维持七个完整稳定任务版本：初始版本加六次完成回溯，当前任务是第七稳定版本。
- NOVA-06 是第六次 Nova 预先留下的固定录像、航迹记录与一次性预签导航授权，不具备当前意识、实时感知或接管能力。
- 当前舰载 AI 可以在生命维持低于安全下限时，使用该预签授权撤销最近一次错误供能提交。是否执行由当前 AI 的安全逻辑判断。
- Nova 通过舰钟漂移、星图校正、航迹残留和事故位置推断共同风险点 S-7；舰载 AI 负责验证航线可行性，不替代 Nova 的洞察或玩家的外部视角。
- 第七次任务致死失败后，系统尝试 `REBOOT 08`，但无法完整重建 Nova 或 Aurora。它是无 `LIVE-07` 的失败壳状态，不是可继续游玩的完整第八轮。
- 最后一次外部握手缓存只允许从 REBOOT 08 回读一次受损的 `REBOOT 07-DAMAGED`。回读后 NOVA-06 录像、预签授权和握手缓存永久不可用；再次死亡将永久断联。

## 当前机制

- `Trust`：Nova 对当前 Observer 的信任，范围 0 至 6。
- `Memory`：玩家对循环真相的理解，范围 0 至 6。
- `Attachment`：玩家与 Nova 的依恋程度，范围 0 至 6。
- `MemoryAnchors`：当前玩家保存的关键记忆锚点，每个锚点只记录一次。
- `ContactStage`：联系人身份揭示阶段，按 `unknown -> named -> verified` 推进。
- 消息投递系统区分发送、送达、重试和通讯链路异常；`prologueFirstReply` 收据也是 Observer 身份建立的持久化依据。
- 所有会改变剧情结果的限时节点使用绝对截止时间持久化，刷新、切换语言或返回菜单不会恢复完整时间。
- 受损第七次可使用正式的“跳过已读”，它与仅在开发环境出现的内部快速测试 Skip 完全分离。

## 特殊互动

V1.0 包含七类正式互动：隔离舱均压、密封记录排序、一次性供能路由、临时记忆封存、新航线锁定、第七协议物理隔离、终章记忆恢复。

供能第一次提交只有在生命维持低于安全下限时才会触发 NOVA-06 预签授权安全回退。通讯不足、核心扫描不足等问题属于提交前校验失败，不会消耗授权。最终提交及 `07-DAMAGED` 中不存在第二次安全撤销。

Aurora 使用分区式人工重力阵列：生活区标准值为 `0.78g`，正常波动为 `0.75-0.80g`；低优先级舱段通常为 `0.15-0.40g`。高潮阶段生活区降至 `0.46g`、维护层降至 `0.18g`、非必要舱段关闭。重力与舱压、空气循环和生命维持相互独立。

## @6 留言

`@6` 保存六份前六次 Nova 留给“下一次的我”的留言。每次有效遭遇恰好有两份正文完全不可读，其余留言局部损坏；E/F 两份价值冲突留言不会同时完全隐藏。遮蔽结果由遭遇与稳定种子决定，刷新、读档或切换语言不会重抽，也不会额外暴露语义。前三次有效遭遇覆盖全部核心语义，但第三次仍保留黑块。

## 结局与后记

- 真结局：接受告别，`Trust >= 4`、`Memory >= 4`、记忆锚点不少于 5，包含 `first_message` 与 `n7`，并正确回答终章五秒问题。
- 普通结局：接受告别，但未满足全部真结局条件。
- 坏结局：拒绝关闭第七协议，或在隔离舱均压、最终供能、新航线锁定、第七协议隔离等致死互动中失败。
- 普通与真结局后记均为解锁后的可选内容，不在一周目结局后强制播放。

## 开发与验证

技术栈为 React 19、TypeScript、Vite 与 Tailwind CSS。项目需要 Node.js 稳定 LTS，并使用仓库中的 `package-lock.json` 安装依赖。

```bash
npm ci
npm run dev
```

完整发布检查：

```bash
npm run typecheck
npm run lint
npm test
npm run build
```

常用剧情工具：

```bash
npm run test:story-audit
npm run validate:story
npm run extract:story
```

剧情资源与界面素材位于 `public/assets/`。第二章使用 `/assets/photo_observatory.jpg`；已删除的 `/assets/nova_observatory.png` 不得恢复。
