版本：V1.0（结构精修版 · 定稿逻辑补全）
说明：本文档在不改变公开版本号的前提下，对现有主线进行正式版前结构精修与逻辑一致性小修。修订重点包括：明确 Observer-01 的本质并前置伏笔、回收“三个月前日志”时间线悬念、重构坏结局动机、让普通结局与记忆锚点完整度更可感知、修正真结局后记语义、强化 NOVA-06 的情感重量、在前半段插入低频异常信号、补充轻量舰内关系痕迹，并新增两次非致命限时选择。本轮进一步补全了 Aurora 号物理回滚规则、小白花异常性质、NOVA-06 残影与主动留档的区别、终章限时回答的情感优先表达，以及坏结局中 Observer-01 无控制权限但拒绝释放索引导致关闭握手失败的逻辑。
修订时间：2026/6/19

【V1.0 结构精修与格式清洗重点】
1. Observer-01 被明确为“真实外部意识获得的临时记忆索引权限”，不是系统创造的人格，也不是普通通讯账号。
2. 前半段加入轻量系统伏笔：外部意识、非舰内人员权限、部分记忆读取权限等，避免第五章反转悬浮。
3. 回收“三个月前日志”：它不是现实时间，而是上一轮任务内时间戳污染当前循环索引。
4. 坏结局动机从“单纯不愿告别”调整为“不敢赌未知风险，选择把 Nova 留在可重复的今天”。
5. 普通结局加入“记忆锚点返还不完整 / 档案完整度不足”的可感知反馈。
6. 真结局后记改为“名字消失，位置留下”，避免“记住你却记不起名字”的语义矛盾。
7. NOVA-06 增加道歉与代价意识，但仍保持残影定位，不成为第二女主。
8. 第一章、第二章在日常中加入低频异常信号，增强悬疑推力。
9. 轻量加入舰长与维修工程师老霍的痕迹，让 Aurora 号更真实，但不扩成群像主线。
10. 新增两次非致命限时选择：第三章通讯异常、第四章失忆证明；二者只影响演出差异，不写入 Trust / Memory 判定，不直接或间接决定结局。
11. 暂不加入 New Game+ / Memory Echo Mode。
12. 统一所有【选项】与【选择：】分支标注格式，便于导入 story.ts。
13. 明确最终选择映射：接受告别进入真/普通结局判定；“维持循环，我还没准备好告别”合并为坏结局入口，避免第三选项造成欺骗感。
14. 将记忆锚点、档案完整度、触发条件等系统层提示改为【记忆档案提示】、【系统浮层】、【触发条件】、【回忆闪回】等非普通聊天气泡标注。
15. 三个结局末尾增加结局后操作提示，形成保存、读取锚点存档或重新接入的体验闭环。
16. 明确 Aurora 号主体物理状态会回到安全记录点；小白花不是上一轮直接留下的实体，而是局部回滚碎片导致同一异常条件反复发生。
17. 明确 NOVA-06 的残影属于协议绑定副作用，OBSERVER 文件与外部索引则是她利用最低限度航行数据保留机制主动留下的内容。
18. 终章限时回答改为“记忆偏移分支”，不再表现为操作失败惩罚；答错或超时仍是情感表达或权限撤销的结果。
19. 修正坏结局权限来源：Observer-01 不控制第七协议，只是拒绝释放外部记忆索引，导致关闭握手失败并触发保护性回滚。
