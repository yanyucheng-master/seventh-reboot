## 1. 观测室隔离与手动均压（bulkhead-isolation）
标题：隔离舱均压
任务：隔离异常源 · 接通安全出口
现场数据：观测室 71 kPa / 过渡舱 84 kPa（LIVE-07）/ 主走廊 101 kPa
Nova 指令：我在中间舱，压力还在掉。
结果 safe：均压完成 / LIVE-07 安全 / 观测室已隔离，过渡舱正在接入主走廊。
结果 injured：均压完成 / LIVE-07 短时缺氧 / 路线正确，但锁定时机偏早或操作延迟使 LIVE-07 一度低于安全线。
结果 fatal 或 timeout：均压失败 / LIVE-07 信号丢失 / 进入第八次重启坏结局链

## 2. 密封记录顺序校验（sealed-record-order）
任务：按“写入者 → 读取者”的顺序提交 NOVA-06 与 NOVA-07 两枚导航签名。
正确顺序：NOVA-06 → NOVA-07。
限制：无致死倒计时；顺序错误只返回记录提示；不消耗 NOVA-06 一次性回退授权。

## 3. 一次性供能路由（power-routing）
标题：观测室应急供能路由
任务：为穿越低压通道和读取残留核心分别配置固定的 100% 功率。每条支路的安全下限均已显示。
通道：
- lifeSupport：生命维持
- communications：通讯链路
- coreScan：核心读取
两阶段安全下限：
- transit：阶段 A / 穿过低压通道 — 生命维持必须保持高位，同时保留通讯与最低核心待机。
- core_read：阶段 B / 读取残留核心 — 核心读取进入工作区，生命维持和通讯仍须高于安全线。
第一次成功：供能稳定 / 未调用残留权限 / NOVA-06 权限未使用并立即失效
第一次失败：错误路由已锁定 / 显示真实后果后执行一次性回退并写入存档
第二次成功：最终供能恢复
第二次失败或超时：最终供能失败 / 不再回退，进入第八次重启坏结局链

## 4. 临时记忆容量管理（memory-seal）
标题：临时记忆容量管理
说明：索引容量不足，只能暂时封存一枚锚点。三项都没有“正确答案”，选择只决定终章由你带回哪段记忆。
可选锚点：
- maintenance_board：贴着眼睛的漂浮维修板
  摘要：Nova 给一块漂浮维修板贴上眼睛，再把自己的乌龙拍给你看。
  封存影响：暂时封存后，她知道图片让自己想笑，却想不起笑点。
- white_flower：不该开放的小白花
  摘要：Nova 没有上报那朵花。她只是每天经过时，多看它一眼。
  封存影响：暂时封存后，她知道花不该出现，却忘了自己为什么高兴。
- goodnight：被认真接住的晚安
  摘要：信道已经安静下来。Nova 说了晚安，另一端仍然有人回应。
  封存影响：暂时封存后，她感觉这个时间本应说些什么，却想不起那句话。

## 5. 航线写入锁定（course-lock）
任务：依据第六次航线包避开 S-7 相位共振区，并完成最终航线写入。
安全规则：普通错误不提交并进入重试；只有主动确认穿越红色核心区或超时才进入致死分支。

## 6. 第七协议物理隔离（protocol-cut）
任务：在新航线保持写入的同时，持续按住隔离控制，切断 PHASE-CORE BUS B。
安全规则：松手会中止本次切断但不会自动判死；倒计时耗尽才进入致死分支。

## 7. 临时封存锚点恢复（memory-restore）
标题：恢复被封存的锚点
说明：三组碎片发生混叠。找出你此前亲手封存的那一组；正确目标由存档固定，不会因刷新改变。
错误组反馈：这组碎片仍在常规索引中，不是此前移入封存区的目标。
- maintenance_board / 贴着眼睛的漂浮维修板：那双眼睛重新清晰起来。Nova 终于想起，这场乌龙从头到尾都是她自己的恶作剧。
- white_flower / 不该开放的小白花：那点白色重新清晰起来。她又记起，它不该活下来，却仍然开花。
- goodnight / 被认真接住的晚安：那句晚安回来了。Nova 也想起，每次断线前缺少的正是这句话。

## 运行时约束
- 第一、第二、第四章不含正式特殊互动。
- 密封记录顺序校验不会修改 NOVA-06 一次性回退状态。
- 第一次供能失败时先落盘 nova06RollbackAuthorizationUsed=true，再播放后果与一次性回退剧情。
- 均压 fatal 与最终供能、航线锁定、协议隔离 fatal 均进入 REBOOT 08 坏结局链。
- 记忆封存不修改 Trust、Memory、Attachment 或结局判定。
- 人工重力降级只表现能源重分配后果，不替代舱压、空气循环或生命维持判定。
